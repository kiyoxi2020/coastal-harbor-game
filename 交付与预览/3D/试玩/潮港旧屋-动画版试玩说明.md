# 潮港旧屋：人物动画试玩版

更新日期：2026-10-09。本版完成 Blender 人物向 Unity 的接入，保留原工程、美术源文件和旧版场景。

## 开始试玩

解压同目录的 `coastal-harbor-animated-macOS.zip`，双击其中的 `CoastalHarbor.app`。本包为本机 macOS 开发版，未作分发公证；尚无 Windows 版本。若系统阻止打开，请先确认文件来源，再按照系统提示处理，不必关闭全局安全保护。

| 操作 | 按键 |
| --- | --- |
| 行走 | WASD / 方向键 |
| 小跑 | 按住左 Shift |
| 转动镜头 | 鼠标右键拖动 |
| 缩放 | 滚轮 |
| 总览 / 跟随视角 | Tab |
| 日景 / 黄昏 | T |
| 查看附近地点说明 | E |
| 返回起点 | R |
| 退出 | Command + Q |

## 本版变化

- 返乡青年替换静态占位人物，带 22 根骨骼和待机、行走、小跑动作。
- 动作随实际移动速度播放；撞墙停止时回到待机。
- 修复导入后的五官取色和发顶表面显示问题。
- 保留旧屋、菜地、鱼摊和码头的地点提示及原有镜头、碰撞、日夜切换。

## 验证与预览

工程检查 11 项通过；本机独立应用中待机、行走、小跑、转向、撞墙停步、码头通行、跌落复位和地面接触共 8 项通过。

`coastal-harbor-animated.mp4` 是自动路线录制的真实 Unity 独立应用画面：960 × 600、30 fps、6.5 秒。不是 Blender 离线渲染，也不代表完整人工游玩验收或性能测试。

工程与完整验证记录位于 `/Users/wyq/Documents/code/coastal-harbor-game`，报告在 `unity/Verification/Character/`。原始 Blender 人物在 `art/characters/returnee/v1/returnee.blend`，游戏侧副本在 `art/characters/returnee/engine-ready/`。

## 当前边界

这是美术与漫步原型，尚无种植、交易、存档或联机。人物尚无手指／面部动画、坡地脚部 IK、LOD 和 Humanoid 重定向；当前静止脚底约有 2.5 cm 碰撞余量，不宣称零滑步。海面仍静态，实时光照与 Blender 预览有所不同，尚未验证 Windows、低配设备和其他分辨率。
