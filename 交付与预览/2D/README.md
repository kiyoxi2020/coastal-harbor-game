# 潮港旧屋 v0.5.2 · 回到小屋

本目录是最新 Mac 试玩与对应源码。打开「潮港旧屋 · 低潮赶海.app」，选择继续游戏或新游戏。

## 新增玩法

- 从旧屋门前按 E：独立门扇开门，人物跨过门槛，再淡入室内；离开同样按 E，能看见开门与关门。
- 单层开放式室内：床与床头柜、厨房、桌椅、旧照片与书架、储物箱、地毯及盆栽。家具具有碰撞和前后遮挡。
- 室内箱子与旧屋东侧箱子共享 48 格仓储，不复制物品。
- 在小屋内退出并继续，会回到屋内；门恢复关闭，位置异常时回到对应场景安全入口。
- 动画期间锁定重复交互；长按 E 不会连续进出，过门时关闭应用会先完成落位再保存退出。

## 试玩路线

1. 从路口向上，再沿菜园后方通道走到旧屋青蓝色门前；看到「E 进入小屋」后按 E。
2. 室内走近床、厨房、旧照片按 E 查看，再按 E 关闭说明。
3. 走到右下方储物箱前按 E，存入或取出物品；B / Tab 返回。
4. 靠近房间下方出口按 E 走出，检查原先已领取的海产不会重新生成。
5. 回屋，打开手账设置并保存返回标题，再继续游戏验证位置恢复。

WASD / 方向键移动，B / Tab 手账，E 查看/开门，R 回当前场景入口。默认窗口面积仍约为桌面的 50%，内部 1280×720；室外镜头不变，室内为单屏固定镜头。

## 存档与限制

新版本读入旧 v1 存档后只在成功保存时写入 v2；备份与错误提示保留。旧 v0.5.1 应用不能读新版写入的 v2 存档，不建议交替运行新旧应用。

Mac 存档目录：`~/Library/Application Support/Godot/app_userdata/潮港旧屋 · 低潮赶海/coastal-progress/`。本轮测试只用 /private/tmp 下专用目录，未改动玩家进度。

床和厨房目前仅可查看，尚不能换日或料理。交易、种植、潮汐计时及每日刷新仍未实现；海产交易是下一独立子项目。

房门使用原图集分区绘制，固定门扇区域不再由房屋绘制；室内家具使用原生像素组件，可独立碰撞和排序。不是把静态概念图放到游戏里。演示为本版本自动化自验的实际录屏采样，含测试中的位置设置与菜单操作。

Mac Apple M4 实测，未 Apple 公证；Windows / Intel 未验证。完整核验见 verification-summary.json。上一版完整归档于项目 archive/2026-10-13-before-v0.5.2/2D，Git 不跟踪历史包。
