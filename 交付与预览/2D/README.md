# 潮港旧屋 v0.5.0 · 海边生活手账

打开本目录“潮港旧屋 · 低潮赶海.app”，从标题页新游戏或继续上次进度。Mac压缩包和源码包均为v0.5.0。应用名称保持原名，避免变更存档位置。

## 这次新增

- 24格背包：分类查看、物品详情、移动/交换/合并、拆分、整理和二次确认丢弃。
- 48格旧屋储物箱：双向转移、部分接收、一键存入同类、独立整理。
- 个人页：姓名、人物预览、累计采集和海产发现记录。
- 标题页、设置、单槽自动存档及上一份有效备份，保存失败有明确提示与重试。

## 试玩路线

1. 选择新游戏并填写姓名。已有进度时需确认覆盖。
2. 沿台阶去沙滩，靠近海产按E拾取；按B或Tab打开手账。
3. 选中物品后移动、拆分或整理。数量用加减按钮选择，支持方向键与E确认。丢弃默认取消。
4. 去旧屋东侧小木箱附近按E，将收获存入仓储；B/Tab关闭。箱内48格可滚动。
5. 手账切换个人页查看生活记录，再到设置选择保存并返回标题。继续游戏可恢复物品与已领取海产点。

WASD/方向键移动；E查看、拾取、确认，普通提示继续按E关闭；B/Tab开关手账或逐层取消；R回路口不清空收获。菜单暂停世界。默认窗口居中、约占桌面面积50%；内部1280×720、原地图与2倍镜头保持不变。

## 保存位置与边界

Mac默认进度在：

`/Users/wyq/Library/Application Support/Godot/app_userdata/潮港旧屋 · 低潮赶海/coastal-progress/`

其他账号使用对应用户的Library路径。progress.json为主存档，progress.backup.json为上一份有效备份，settings.cfg为独立设置。测试使用/private/tmp下专用目录，没有覆盖正式玩家进度。

六个固定海产点不会每日刷新；全部收集后可从标题确认新游戏。交易、种植、日循环、体力、技能、任务与音乐音轨尚未开放。旧v0.4.4没有持久存档，无法恢复已退出的临时收获。

Mac Apple M4实测，未Apple公证，Windows/Intel未验证。当前文件夹仅最新版；旧交付移至项目archive/2026-10-13-before-v0.5.0/2D，完整保留且Git忽略。详细验证见verification-summary.json与各测试报告。
