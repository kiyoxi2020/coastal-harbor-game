## 操作

- WASD/方向键移动。
- 靠近地点按E查看；窗口打开后再按E继续。当前说明是单页，因此再按E即关闭。
- 长按E不会反复开关，无附近地点时不会弹出旧提示。R回路口并关闭窗口。
- 不再使用Esc关闭；窗口内与底部操作提示已更新。没有额外加入分页系统。
