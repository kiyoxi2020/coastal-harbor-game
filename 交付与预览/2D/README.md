# 潮港旧屋 v0.5.1 · 像素手账 B 版

打开本目录「潮港旧屋 · 低潮赶海.app」。本次按已确认的 B 版概念重建可缩放像素菜单，文字、格子和数量均为真实交互界面，并非整张概念图覆盖。

- 右上角删除固定库存文字，换为背包图标；点击或按 B / Tab 打开。
- 青蓝外框、奶油纸卡、阶梯轮廓、像素缝线、珊瑚色标签与选中格。
- 保留 24 格背包、48 格仓储、拆分、移动、合并、整理、丢弃确认、个人页和设置。
- 默认窗口仍约占可用桌面面积 50%；内部 1280×720、原地图和 2 倍镜头不变。

## 试玩

新游戏填写姓名，或继续已有进度。WASD / 方向键移动，E 拾取与查看；普通提示按 E 继续和关闭。点击背包或按 B / Tab 打开手账，方向键选择、E 确认，B / Tab 返回。旧屋东侧木箱按 E 打开仓储。菜单暂停世界。

v0.5.0 存档格式及应用名称保持不变。Mac 默认存档：`~/Library/Application Support/Godot/app_userdata/潮港旧屋 · 低潮赶海/coastal-progress/`。主存档 progress.json、上一有效备份 progress.backup.json，设置 settings.cfg。验证使用独立临时存档，未触碰玩家进度。
