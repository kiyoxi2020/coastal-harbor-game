# 1280×720渲染与地图规范

v0.4.4保留1280×720内部视口，启动时使用居中普通窗口，面积约占所在屏幕可用桌面的50%，不最大化、不全屏。宽、高分别取可用桌面的约70.7%，只在每次启动时设置一次，随后可手动调整。

按用户纠正，已撤回v0.4.2的扩地图及1倍镜头：地图恢复640×416世界单位、原五棵树，镜头恢复2倍缩放，视野640×360世界单位。建筑、人物、碰撞和交互点均恢复v0.4.1对应状态。所需变化是整体画面在桌面上更大，而不是显示更多地图。

HUD在1280×720坐标中独立绘制，中文正文24像素，背包和底栏按视口边缘定位；不会跟随世界镜头移动。保持E查看/拾取/关闭及R返回规则。

窗口使用viewport等比适配与fractional缩放，画面随窗口缩放。内部仍为1280×720；nearest过滤保留，非整数屏幕比例可能出现像素宽度不均。与16:9不同的窗口比例会保留必要边缘。

发布验证额外读取独立Mac应用的实际窗口模式和尺寸，并与所在屏幕的可用桌面区域比较，不只检查内部渲染截图。

验证包含test_display.gd的内部尺寸、镜头跟随/限位、沙滩角色可见、HUD尺寸与字体，以及原有五组玩法回归和实际渲染路线。当前改动不自动提交Git。
