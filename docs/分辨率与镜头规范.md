# 2560×1440 渲染与地图规范

2026-10-16：内部视口由1280×720提高到2560×1440，宽高各2倍，像素总数4倍。`project.godot` 的 display/window/size/viewport_width、viewport_height 分别设为2560和1440，stretch/mode仍为viewport。window_width_override/window_height_override保留1280×720；启动脚本仍按可用桌面面积50%设置居中普通窗口，随后允许手动调整。

主场景WorldCamera.zoom由(2,2)改为(4,4)，世界视野保持640×360；地图、人物尺寸、碰撞和交互坐标不变。

HUD及Journal的CanvasLayer.scale为(2,2)，Root固定逻辑布局1280×720；子控件沿用原坐标、字号与边缘锚点。绘制到1440p时占用2倍像素，窗口内相对大小不变。转场Fade仍按完整视口锚定，不乘UI缩放。

NotoSansCJKsc-Regular.otf.import的oversampling由自动(0)设为2，以更高精度栅格化中文。像素素材仍使用nearest，原始位图未重绘；提升的是绘制分辨率与文字采样精度。viewport仍等比fractional适配，不同长宽比保留必要边缘。

验证：显示合同、编辑器场景合同及原生2560×1440截图；测试存档和截图放在/private/tmp/coastal-*。不自动导出、提交或推送。
