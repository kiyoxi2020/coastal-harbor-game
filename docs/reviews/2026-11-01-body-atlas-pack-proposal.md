# 身体归档切分与打包待执行方案

南北向锄头的无工具身体参考已从Q17认可的带工具源同步，12姿态经过同姿态原生对照；Q17实际带工具图、时序和配置哈希未改。身体与工具不是像素完全相同的可分离层，换装覆盖和严格接触不由这次同步授予。

这份方案尚未执行图像处理。逐帧输入、SHA、源矩形、整帧尺度、根点、时序及alpha外框在同名JSON中，共24身体动作方向/108姿态，另56带工具可见姿态引用。读取源图alpha外框后，现有预览尺度下最大范围为根点左114.84、右114.50、上165.63、下14.25像素。

统一格子采用256×224，根点(123,201)，方向按north/west/south/east行，帧按时间列；保持当前整段动作的整帧显示尺度，以nearest形成派生输出，不覆盖或缩小原始PNG。每个源格只进行一次整帧缩放与整数登记，不单独移动/缩放手脚或衣物。当前比例仍是候选显示尺度，最终统一密度需在打包后原生核对，不能由登记自动视为冻结。

身体六张约23.625 MiB，连带工具三张合计35.875 MiB；这是全部同时解码的RGBA估算，不是PNG磁盘体积、GPU完整峰值或运行时常驻承诺。

拟写入：`art/characters/parts/body/adult-v1/r001/`（派生身体、完整带工具动作、manifest），`art/characters/layouts/adult-v1-r001.json`（公共布局）；采用的完整原图和提示词留在现有sources。过程截图/录像/日志继续仅在/private/tmp/coastal-visible-atlas-body-r001。正式运行目录与runtime-baseline不切换。

允许的操作限定为按JSON列出的源矩形切分、整帧nearest缩放/登记、按方向/帧号打包和记录输出哈希。保留生成alpha，不清理背景alpha、不重画像素、不贴脸手、不删除人物区域，不提取独立锄头层。处理代码使用现有tools/characters入口能力；缺少能力时先定义最小扩展和相应测试，不在资源批次新建合成器/播放器。

打包后必须复核全部源/输出/配置哈希、尺寸与边界、原生显示和连续切换。严格支撑/滑步、握持/落点、世界遮挡及整套视觉认可仍未通过；manifest必须明确未通过项，不能把有图/可加载称为归档完成，也不因此启动衣物A/B。
