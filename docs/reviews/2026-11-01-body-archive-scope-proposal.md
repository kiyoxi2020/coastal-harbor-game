# 身体源归档范围：待决定

当前可审阅对象没有重新生图：Q19/Q20认可的九张图集、统一布局、两份可复核严格构建，以及实际原生材质点量测。来源、产物、用户认可和可重建命令逐项绑定在同名JSON。

108个可见下缘皮肤材质点，固定41×41ROI，原生对应全部在原有≤1像素/RGB界内。源点由实际canonical源图定位，保留源atlas坐标和整格裁取关系；没有用截图拟合位置，也没有把颜色阈值当作ownership或解剖脚位。该结果只证明所选像素正确显示，不证明它是支撑脚、机械握点或合法地面接触。

实际世界记录还显示，同一离散姿态保持期间，固定材质点会跟随角色平移；走路观察间隔内约3.6–14.4原生像素、跑步5.4–21.6像素。这个数值没有指定真实支撑阶段，不能直接当作“滑步失败”；它说明像素对应≤1px与物理脚点固定是两种不同检验，不能混写为一个通过。Q20已经认可当前实际世界视觉，原记录不撤回。
