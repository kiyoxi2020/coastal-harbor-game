# P10企业与家庭消费 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. 本轮遵照AGENTS由主代理集成、独立迁移子任务并行；不自动提交。

**Goal:** 按P08已批准基线3建立可保存、可对账的有限企业经济，不启动P11画面。

**Architecture:** 纯Town规则结算，Day统一推进日期，Life统一序号/事件，ActionService保存后发布。交易通过同一参与者适配器预检现金、库存、容量和额度；town库存唯一真相为slots。

**Tech Stack:** Godot 4.7.1 / GDScript。

- 所有测试存档/private/tmp/coastal-*；Godot显式--log-file /private/tmp/coastal-P10-*.log。
