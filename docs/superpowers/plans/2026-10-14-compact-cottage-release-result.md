# v0.5.4 紧凑小屋发布验收

2026-10-14（Asia/Shanghai）。基于已批准的北墙入口规格，运行代码提交为 `9eff3fa`。房间为288×208逻辑单位，人物48×48动画画布、2倍镜头与1280×720内部画面保持原比例。默认窗口约占可用桌面面积50%。

## 完成范围

清单包含17项生成图资源：保留床与门三态，补齐床头柜/灯、厨房、餐桌、椅、箱、书架、照片、植物、窗帘窗、两块地毯、墙、地板。左右两窗复用同一资源。全部资源实际加载，家具实体底座与资源元数据逐项一致；挂墙物不产生空气障碍。原图、提示词、确定性整理工具和处理结果保留在源码包中。

两侧门前深度0–56、横向±24连续可交互，近门对齐不先后退。自动走动为72单位/秒的真实碰撞移动。人物进入门洞后逐步遮挡，外门的世界坐标上边界防止头发画在雨篷上；完全进洞后才开始淡出。切换、失败恢复、读档和R重置均清除额外遮挡。室内合法旧坐标保留，旧南门/家具内等非法位置返回(320,160)，存档版本仍为2。

导出应用四组流程合计173项通过。不同测试覆盖会重叠，不把这些数字相加宣传为独立功能数。缺失目标与不可能写入路径是刻意故障注入；写入失败有明确提示且断言通过。沙盒中的无窗口Godot可能输出macOS证书库错误，相关进程仍正常退出0。

门外头发遮挡有真实渲染RED/GREEN：新增测试在修复前检测到雨篷上方人物像素，修复后该区域为零且门洞下方仍有可见人物像素。原生关键帧与导出应用连续录像分别检查；录像为约10Hz采样帧，编码30fps（重复帧），不是30Hz原始采集。导出实际画面、连续46帧及双方独立视觉检查均未见雨篷上方头发、脚踩关闭门扇或地板上的角色被过早隐藏。

发布模板不支持`--script`，因此未把尝试运行导出包内独立SceneTree脚本计为通过。该尝试只到标题画面并停止，没有新建/继续游戏或保存进度；可用的导出验证入口是`--verify-house`和`--verify-journal`，这些入口全部使用/private/tmp专用存档。原生独立脚本的45项渲染测试与导出流程173项分开记录。
