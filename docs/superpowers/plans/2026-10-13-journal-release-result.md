# v0.5.0 第一阶段交付结果

已完成并接入游戏，不再只是库存底层模块。

## 可试玩内容

## 实现边界

- player_state.gd为唯一玩家状态，旧foraging_state.gd保留兼容入口，数量由格子库存派生。
- save_service.gd统一快照校验、临时写入、备份和恢复；settings_service.gd独立保存设置。
- ui/journal.gd承载当前三分页与模态窗口，harbor.gd协调世界、仓储入口、标题与保存。
- 没有加入资金、体力、换装、任务、交易、种植、日循环、资源刷新或音乐音轨，也没有变更3D工程。
