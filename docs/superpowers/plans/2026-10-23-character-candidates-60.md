# 六类各10候选执行计划

> 2026-10-23范围说明：本计划仅用于六类各10静态候选的原任务与交接，未勾选项不代表尚未生成，完成情况须核对实际证据；不规定后续动态制作顺序。 后续人体与衣物运动制作统一遵循[版本2规范](../../design/character-art-pipeline.md)。

用户明确授权持续执行直至全库人体/头发/上衣/下装/鞋/帽各10候选。沿用已认可v3与第一套衣裤鞋，目录和验证记录不算设计，四方向不重复计数。

- [x] 读取当前状态、统一管线、选择元数据、现有组件、Git并确认用户本轮授权。
- [ ] 复用有效六类各1款，建立60设计清单、唯一ID、原图/提示词/四向/遮罩/兼容性字段。
- [ ] 先做第二套上衣/下装/鞋，验证真实逐槽替换与接缝，再继续其余候选。
- [ ] 用GPT逐设计制作其余头发、上衣、下装、鞋、帽各9款；保留原图/提示词，提取原位组件，禁止为凑数程序换色。
- [ ] 制作9个人体母版候选，包含女性、老人、儿童；每个体型独立模板/比例，新模板尚未认可时不把成年组件自动适配上去。
- [ ] 验证全库6×10实际组件，四方向、来源哈希、模板/姿态、保护区域、可见皮肤归属、有限声明组合。
- [ ] 原生明暗背景查看逐设计四向、透明层，检查头面线条、领袖/裤腰/踝鞋接缝；拒绝稿不计候选。
- [ ] 保存原生证据绑定和可浏览目录，更新唯一当前进度；区分候选完整、待用户挑选、适配/裸模/动画未完成。

完成条件：目录六类分别10个独立设计，非人体类含真正可查看透明组件和穿戴预览，不仅全身图；每个计数对象有源图/提示词/四向/元数据/证据。体型参考不是裸模/动画，数量不替代审美认可。全身改图的非目标像素不带入母版；未知适配不能默认通用。检查已知支持组合，不做10^6穷举或正式衣柜/P12。

分工：主代理全部GPT设计/遮罩/合成/视觉集成；gpt-6.1-sol high独立负责目录验证与原生总览工具，因60设计的元数据一致性和分页显示需要；不嵌套。不提交/推送/导出，不替换正式角色，不覆盖既有交付。
