# 港口场景人物步行体验 Implementation Plan

目标：按用户要求把西向动作小样放入真实游戏环境体验并降低速度。默认0.75倍：54世界单位/秒，四姿态各106.667ms；滑条0.5–1倍同步缩放位移与时钟。主代理直接执行，不提交。

方案：独立开发场景复用harbor_exterior.tscn的真实地形/碰撞/y排序与world_camera.gd镜头。使用同一baked A/B小样和根点，不引入旧脸手或镜像伪造其他方向；只有A/左键西向，R显式回起点、1/2衣物、停下保持当前姿态（不是新idle）。场景和UI布局在tscn；逻辑、来源哈希检查与时序在gd。正规主场景和发布清单不变，无存档服务。用户本轮请求授权游戏场景体验，不视为小样美术认可或正式迁移。

文件：godot2d/dev/character_walk_trial.tscn、character_walk_trial.gd；tests/test_character_walk_trial.gd；小样目录launch-game-trial.command、体验README与本轮证据。

- [x] 先写失败测试：可加载体验场景、真实港口/碰撞、来源哈希、默认速度/动画同倍率、两套服装同相位、缺资源拒绝、停下不播、碰撞不继续走、正式主场景不改。
- [x] 实现场景及最小控制器，添加一键启动脚本（Godot日志/private/tmp/coastal-*，不调用存档服务），通过上述检查。
- [x] 原生键盘/按钮/滑条/移动与截图验收；保存哈希、实际位置/帧/速度记录，检查原生尺寸、环境遮挡与碰撞。
- [x] 更新状态和使用说明，启动体验窗口交用户操作。未有新问题不重跑全玩法回归，不导出、不提交。

边界：只有西向walk与固定光头/裤鞋，未支持右/上/下或农事动作。缩放仅整帧统一138/582/4世界比例，根点[256,708]；不得单独变形/挪衣鞋。体验速度独立，不改上一轮80ms证据或生产速度。

结果：21项隔离和18项原生键鼠检查通过。原生截图已查看，证据与使用说明位于小样GAME-TRIAL.md。场景为独立开发入口；未进行完整门/农事/世界遮挡生产回归，不宣称全套动作兼容。
