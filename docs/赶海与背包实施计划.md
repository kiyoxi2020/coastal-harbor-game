# 赶海与背包 Implementation Plan

**Goal:** 在既有地图完成六点拾取、三种库存与E键互斥交互。

**Architecture:** 独立RefCounted状态处理库存及领取记录；Node2D负责物品绘制；场景入口协调输入；HUD显示状态。地图数据统一沙滩范围、点位、碰撞。

**Tech Stack:** Godot 4 / GDScript，沿用640×416与nearest缩放。

## Global Constraints

不加入交易、存档、计时或随机刷新。R只返回路口。E关闭窗口不能穿透拾取。固定低潮、六点各领取一次、三种数量各二。不修改3D。用户已批准设计，当前会话直接执行；executing-plans技能不可用，采用本地逐步执行及检查点。
