# 像素手账 B 版接入 · v0.5.1

用户选择 B 版概念后，使用 Godot StyleBox 重建可缩放界面，而非将生成图烘焙为不可交互背景。

实现位于 scripts/ui/pixel_style.gd、backpack_icon.gd 和 journal.gd：阶梯角、双像素边线、有限色阶、缝线、纸卡与珊瑚选中态。图标入口替代旧固定库存文字，保留键盘入口。所有页共用样式，背包、仓储和存档逻辑保持原规则。

测试新增像素样式资源检查、背包按钮存在与打开行为；原 HUD 计数测试改为拾取反馈检查。原 24 格背包和 48 格仓储等回归继续执行。源码测试、导出应用实测、重启恢复报告见最新交付。

生成图保留在 art/godot2d/ui-journal-concept，仅作设计参考。当前落地并非生成图的逐像素复刻，使用原有中文字体与物品图标。未更改存档格式、内部渲染分辨率、镜头或默认窗口比例。
