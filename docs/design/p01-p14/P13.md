# P13：住房、岗位与首次家庭迁入

前置P12。范围仅一次3人家庭迁入，不做生育死亡、第二户生成或无限扩镇。

## v7身份与住所

P08每户members数字保留，增加member_ids、worker_ids、residence_id；town新增residents/residences/jobs/migration。人口只取sum(household.members)，并校验每户members==member_ids.size()，不另存可变total_population。

初始hh_01..hh_05各4成员，ID按户名+_w1/_w2/_d1/_d2；前两位为可就业成年，后两位为不计劳动力的成员，不模拟具体年龄。例hh_01.member_ids=[hh_01_w1,hh_01_w2,hh_01_d1,hh_01_d2]。residents每项{household_id:String,working_age:bool,job_id:String,skills:Array[String]}，P12三个resident_id映射既有人，不能新加3人口。

residences：home_01..home_05容量4、occupied_by依次hh_01..hh_05、repaired=true；home_returnee容量3、occupied_by=""、repaired=true。前5户为后台存量住房，不要求此任务新增5座地图建筑；必须在报告区分后台住宅与可见返乡住宅。

初始岗位：restaurant_cook→hh_01_w1、restaurant_helper→hh_02_w1，skill=general、employer=restaurant、wage4、enabled=true；其余8位worker分别占offsite_<resident_id>岗位，employer=offsite、skill=general、wage0、enabled=true（其家庭12G生计收入仍由外部基金支付，不能再按岗位发一笔工资）。初始没有失业成年人，外部就业不主动抢占本地新岗位。

jobs每项固定{employer:String,skill:String,wage:int,enabled:bool,occupant:String}，residences每项{capacity:int,occupied_by:String,repaired:bool}。

新增restaurant_processing岗：skill=processing、wage4、occupant=""、enabled仅restaurant.status==operating。初始居民skills=[general]；候选成年之一skills=[general,processing]，另一位[general]。此约束避免“本地优先”把唯一迁入岗位先占掉；不能偷偷跳过本地失业检查。

migration={done:false,last_evaluated_day:0,reasons:[]}。候选固定hh_returnee，3人IDs returnee_w1/returnee_w2/returnee_d1，workers2、初始预算200、eligible_from_day=迁入源日+1；预算从external_fund扣200，来源明确，不能把基金不足当负余额继续迁入。

## 每7源日评估与原子迁入

population_rules.evaluate仅在source_day%7==0且source_day>last_evaluated_day时执行；不满足评估日正常返回无变更。评估在本日日常消费后，设置last_evaluated_day并记录拒绝原因；重复睡眠已由日结去重。

条件全部满足才迁入：

1. migration.done=false；餐馆operating且cash>=100。
2. food_history恰有最近连续7个源日，各日total>0，sum(served)/sum(total)>=0.75。
3. home_returnee已修缮、空置且容量>=3。
4. processing岗位启用且空缺；先从现有本地失业成年人中按ID选skill匹配者，有则分配该岗、记录local_hire，当次不迁入（以后需另有岗位）。不把已offsite就业居民当失业。
5. external_fund>=200，候选身份/家庭尚不存在。

成功在同一候选快照新增家庭/居民（新户residence_id=home_returnee、member_ids为候选3人、worker_ids为两位成年ID），预算转账、占住宅、分配returnee_w1到processing岗、done=true、记录family_arrived事件。returnee_w2先失业，不为凑数字自动生成工作；返乡3人中2劳动力，新增1就业1失业。次日起第三名餐馆员工才加入工资/产能；将M2 employee_households更新为从岗位派生的兼容视图，唯一就业真相为jobs，不能两边独立编辑。

迁入当晚源日仍5户消费，下一源日6户；住宅与NPC表现读取同一已提交状态。没有满足条件记reasons：restaurant_not_ready/food_unstable/no_housing/no_job/local_worker_hired/fund_shortage，不回滚已合法完成的全日日结。

## 视觉与场景

returnee_residence是现有陆地上的小屋外观实例，含BaseCollision、InteractPoint、DarkWindows/LitWindows、NameLabel。初始候选位置(560,80)，需按P11相同占用与可达标准先验证，冲突时记录最终位置；不新增室内与传送入口。迁入后亮灯、门前出现箱/晾衣等静态布置至少两项可见变化，材料开发占位明确记录。空屋不能提前亮灯。可见居民仍P12三人，新户本轮以住宅生活痕迹表现，报告不宣称已完成新户寻路精灵。
