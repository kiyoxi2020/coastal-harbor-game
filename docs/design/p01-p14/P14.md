# P14：小镇报告、垂直切片与阶段评审

前置P13。交付可解释报告、20～30分钟切片验证与阶段结论；不自动开启M4。

## 文件与接口

新增scenes/ui/pages/town_page.tscn、tests/test_life_town_report.gd、test_life_vertical_slice.gd；修改report_builder.gd增加town(data:Dictionary)->Dictionary，ui/journal与journal/pause_menu场景新增“小镇”入口。测试报告写本卡执行记录，不另开多份互相冲突的进度总表。

report_builder只读，不保存、不发钱、不评估迁入。返回固定结构：

```text
day_id:int
population:{total:int,households:int,workers:int,employed:int,unemployed:int}
housing:{capacity:int,occupied_people:int,vacant_homes:int}
restaurant:{status:String,cash:int,last_sales:int,last_cash_profit:int,reason_codes:Array}
food:{window_days:int,served:int,demand:int,ratio:float}
migration:{done:bool,reasons:Array}
recent_events:Array（最多10条，源数据已有事件）
suggestions:Array[String]
```

food.ratio=served/demand，demand0时ratio0且显示“暂无需求数据”，不是100%。日结历史不足7日显示实际天数，不虚构7日平均。population/employment从家庭成员和岗位推导，不从NPC节点数/顾客数推导。经营现金利润按P08标签，不能叫GDP/增加值。贸易/生态尚未实现，页面显示“尚未开放”，不能编造增长曲线。

建议规则按优先级：缺房→“返乡住宅尚未准备好”；缺岗位→“餐馆稳定营业后可开放加工岗位”；食品不足→“查看餐馆缺料或资金原因，尝试供货”；餐馆关闭→“补足一批原料并开启试营业”；满足条件等待评估→“每7日评估一次返乡”；done→“新家庭次日起参与小镇生活”。未满足项可并列，不输出无关的贸易进口建议。

人口变化、住宅亮灯、餐馆营业和日报引用同一已提交快照。world刷新后所有相关表现必须一致，不能只刷新数字而保留关闭招牌。

## 自动集成路径

从最新版本默认新游戏开始，day1买种各1、种两畦、采卖海产；在day3收获生菜后，向餐馆供clam1/lettuce1并开启试营业。每天浇水/成熟收获，可供货但不能直接改状态；先连续睡眠至源日7评估，开业前2日食品不足应拒绝迁入，再持续经营至源日14，最近7日食品满足率>=0.75，完成首次迁入。若经济默认值不能自然达成，按每日metrics定位并修订方案与测试，禁止测试直接设置migration.done或人口23。

test_life_vertical_slice必须调用正式ActionService/规则，使用真实隔离SaveService；源日3、6与13退出状态对象再加载，模拟会话恢复。终点day15人口23、家庭6、迁入一次、房屋住户一致；再结算源日15检查新增员工和消费，不要求此步仍停在30分钟体验内。

## 测试与试玩清单

- [ ] test_life_town_report：20/23人口、缺房/缺岗/缺食原因、0需求、少于7日、只读不变、未开放贸易状态。
- [ ] test_life_vertical_slice：种植/赶海/买卖/试营业/自主经营/返乡全链、日结重载、全镇资金守恒、唯一家庭与岗位。
- [ ] 必要回归：新增P02–P13测试与相关原有存档/房屋/交互/显示合同。若历史基线失败仍存在，写清是否影响本次放行。
- [ ] 原生20～30分钟体验：从新游戏开始，通过操作完成至少一次种植收获/供货，并看到餐馆与住宅的可见变化；不得用开发者直接改人口替代。
- [ ] 外部试玩若有参与者，记录实际人数/耗时/反馈；没有则明确“仅开发者试玩，外部体验未验证”。

人工表每行必须填写实际：新建引导→买种→种浇→赶海/售货→床睡眠→餐馆开业→自主采购→返乡提示→住宅亮灯→小镇原因页。预期包括操作可达、输入不穿透、信息可读与状态一致；截图至少含餐馆前后、返乡住宅前后、小镇报告。

## 放行决定

通过硬条件：数据/存档/守恒测试全部通过；默认路径能在源日14自然20→23；餐馆无人持续供货仍可营业；至少两条有效收入途径；重要事件可见；无生产阻塞。体验条件：试玩能回答“现在可做什么、餐馆为何变化、家庭为何迁入”。没有外部试玩不能宣称外部理解度达标。

结果只能是：M0–M3闭环完成/待验证/需修改，附证据与未验证边界。P14通过不等于Alpha或可发布；M4需依据玩法评审另立具体任务。有限depot、开发占位美术、非完整昼夜日程与未验证平台须进入下一阶段风险清单。
