# P05新版设计：逐格菜地与GPT美术

2026-10-19；状态：用户已批准并实施，验证记录见[P05](P05.md)。用户明确要求替换此前“整畦一株”的方案。当前P04与P05实验修改均保留，不提交、不清理或覆盖。P06尚未开始。

## 目标与推荐方案

参考成熟种田游戏的逐格土地与工具操作，将旧屋前的两片装饰菜畦改为地面式种植区，每片4列×2行，共16格。每格独立翻土、播种、浇水、成长与收获，可混种生菜和番茄。人物可走入田间，普通作物不阻挡行走。

推荐起步16格；每格16×16世界单位，单片土地区域64×32。保持两片种植区的大致位置与中间通道，实际边界须结合房屋、道路和玩家脚底碰撞复核。不为了凑格数挤占房门或海边道路。

| 方案 | 体验与代价 | 结论 |
|---|---|---|
| 地面式逐格种植 | 能进入田间、直接选格，后续扩展自然；需移除旧菜畦整体障碍并接逐格状态 | 推荐 |
| 木框抬高菜床内分格 | 更接近旧布景，但中间格的可达距离与外围操作较绕 | 备选，不作为默认 |
| 只在现有整畦上画网格 | 改动少，但不能保证每格独立状态与操作 | 不采用 |

## 参考依据与取舍

- [Stardew Valley Wiki: Crops](https://wiki.stardewvalley.net/Crops)：土地先耕作，种子逐格种植；未浇水时不增长而非立刻死亡；作物有独立生长阶段。
- [Stardew Valley Wiki: Watering Cans](https://wiki.stardewvalley.net/Watering_Cans)：浇水是对土地/作物格的工具操作。

以上是参考游戏的机制资料。本项目的16格规模、16单位格宽、工具键位、无体力约束和迁移规则均为本次建议，不是资料中规定的实现方案。只借鉴空间与操作方式，不复制其他游戏素材、UI或完整数值系统。

## 土地与操作

不再把整片GardenA/B作为一个可种植对象。区域用于摆放与编辑，真正操作目标是区域内的单格，例如garden_a:0:0。区域移动后，格坐标、作物根点、选中提示和操作距离统一随区域变换。

推荐四个工具槽：锄头、水壶、种子、手。数字1–4选择工具，种子槽的小选择条切换生菜/番茄。鼠标指向或人物朝向确定目标格；只有相邻可达格可以操作，不能跨地图遥种。

- 锄头：把未耕地变成可种植的土壤。
- 种子：一格消耗背包里一颗当前种子；一格只能有一株作物。箱子不自动参与。
- 水壶：浇当前单格，湿土明显变深；已经浇过的格子不重复扣操作。
- 手：收获成熟的当前格。容量不足时不收获、不清空作物。

鼠标点击或E使用当前工具，每次先只操作一格；E保留门、仓储和提示关闭的既有优先级。打开面板时世界操作停止，关闭后等待松键。首次不做长按连种、蓄力范围浇水、自动识别工具、体力/耐久或季节死亡。也不再为每次浇水打开遮挡大半屏幕的整畦页面。

## 逐格状态与日结

土壤与植物分开：土壤记录tilled/watered，植物记录crop_id/growth，预留fertilized。空地也可以先浇水再播种；收获后仍是耕地，土壤当日湿度保留。换日清除当日浇水状态；只让已浇水的未成熟作物增长一次。

先保留原型生菜2个有效浇水日、番茄4日，以及每次收获3个的测试基线；更多格子会改变产量与操作量，P07必须重新做7日经济与劳动量验收，不能沿用旧结果宣布平衡。

所有命令带唯一cell_id，仍走P03候选→校验→保存→发布事务。失败不扣种、不增长、不清空成熟作物；同请求重放不重复结算或发产物。日结的mature_plots改为实际新成熟格的ID列表，不把区域整体算一株。

存档需要新版本，不能把现有v3的两块plots直接解释成16格。新增v4逐格版本，原定企业v4/人口v5依次顺延；实施时已一起修订共享合同及相关任务卡。迁移旧plot_a/plot_b时，将已有作物及生长、浇水状态各保留到所属区域首格，其余格为空；不能复制成8株。钱包、背包、箱子、日期、序号与回执不重置。历史日报的成熟ID做明确映射，旧回执仅用于兼容去重。

## GPT美术方案

视觉草案：[concept-v1.png](../../../art/design/farming-grid-v2/concept-v1.png)。该图由内置GPT生图工具生成，是概念板，不是游戏运行截图，也不是可以直接切入引擎的成品图集。

土壤、作物和选中提示必须分别制作：

| 资源 | 初步规格 | 关键要求 |
|---|---|---|
| 土壤瓦片 | 16×16逻辑像素，干/湿两套，含边/角/中心连接 | 可拼接，格子边界靠土色和垄沟提示，不画粗黑棋盘线；空地不能自带成熟蔬菜 |
| 生菜 | 16×16或16×24透明画布，至少播种/幼苗/成熟 | 根点统一，成熟为可辨认的包心叶丛；2日规则只映射有效阶段，概念板多余阶段可保留备选 |
| 番茄 | 16×24透明画布，播种/幼苗/成长/成熟 | 红果识别清楚，向上生长，不侵占邻格根点；首版不做阻路的架架碰撞 |
| 选格提示 | 16×16透明叠层 | 四角细框；可操作浅黄，不可操作淡红，不烘焙进土壤 |
| 操作反馈 | 小范围翻土/浇水/收获像素反馈 | 与实际事务结果对应；写盘失败不播放成功收获或隐藏作物 |

风格匹配当前红瓦旧屋、青蓝木构、暖色石路与海港环境；斜俯视2D、有限色板、清晰像素簇。土壤始终在地表层，作物以脚底根点排序，人物遮挡遵循真实空间。正式生成时先产独立透明素材，再检查尺寸、alpha、像素密度、边缘拼接和锚点；不把整张概念图缩小后冒充可用图集，不再以大色块几何形状作为最终植物。
