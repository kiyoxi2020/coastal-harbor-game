# 人物返工复盘与统一管线

2026-10-22。此前按用户要求，独立复查实际使用gpt-6-astra、high；复盘基于可见图片、代码和验收记录，不推测私密思维过程。用户随后要求统一人体管线并清理错误过程，本页已合并为结论索引。

## 可观察的问题

1. 认可完整人物后重新生成通用人体，再按总高百分比定位衣鞋，导致比例与接口漂移。
2. 新身体叠旧脸/手使透明轮廓重复；固定旧坐标无法保证整套绘制一致。
3. 用暗色连通块和颜色阈值推断发型，可能把眉、鼻、耳线带入头发或帽子。
4. 文件数量、少量采样点和原装还原检查不能证明换装、完整脸轮廓、衣鞋贴合和审美正确。
5. 原生证据没有绑定最终纹理版本；旧截图和旧通过计数不能验收后续修改。

## 采用的方案

用户选定的[新母版](../../../art/design/character-bodies/adult-standard-v1/source.png)是唯一成年标准站立外观来源。保留其自身的脸、头型、手脚和比例；允许一次整帧坐标注册，不继承旧A坐标限制。它目前穿衬衣与短裤，尚不是隐藏区域齐全的裸体模板、完整组件库或动画骨骼。

所有具体制作、图层归属、接口、16帧验证、扩量和证据哈希规则，以[统一人体管线](../character-art-pipeline.md)为准，本页不维护另一套步骤。

旧A/B、女性/老人/儿童的已认可参考仍可从[人体索引](../../../art/design/character-bodies/README.md)打开。失败源图、脚本、组件及过时方案按用户清理授权移出工作区，保留[可恢复备份与清单](../../../art/archive/README.md)。旧测试数字不再作为当前完成状态。

当前面部基准为三向眉毛v3；已制作静态衣裤鞋接口、第二套静态交叉预览，以及[六类各10项外观候选目录](../../../art/design/character-candidates-v2/README.md)。批次最终视觉交接尚未完成，包含男童体型高度待修问题；目录数量不代表全部认可、跨体型兼容或动画可用。

2026-10-23动态人体与衣物组合已纳入[统一人体制作规范版本2](../character-art-pipeline.md)。当前路线为：单一外观母版与静态接口→单侧四帧运动小样→四向idle及walk/run/hoe/water/harvest→两套衣裤鞋8种混搭及无帽/有帽验证→生产接入与扩体型。动画验证前置，所有动作的姿态映射允许复用同一部件视图。

衣物源图保留目标动作所需隐藏区；source_ownership负责源图提取，coverage负责衣物覆盖身体，occlusion负责当前姿态前后关系。正常动作锚点位移合法，禁止任意挪动/缩放补错位。资源合同、合成顺序、时钟/脚点/工具事件、证据与阶段出口均只在统一规范维护。

[Astra运动评审与游戏实现调研](NPC-motion-astra-review.md)保留原因与来源，原重复建议已合并，不再作为平行规范。设计已完成，已生成两份西向四帧动作试稿，尚未通过比例与步态验收；当前仍执行body01西向四帧walk、两种袖长的小样，未替换生产角色。新版最终覆盖旧版全部五类四向动作，完成后统一切换到唯一现行人体体系，旧模型退出运行和发布依赖，不长期新旧混用。新动作、样式、体型按稳定ID、能力清单、姿态映射与增量验收扩展；具体合同及迁移规则见统一规范。
