# NPC人物参考与现行制作入口

NPC需要在发型、服装与轮廓上区别主角。组件方向仍为身体、头发、上衣、下装、鞋、帽，全库每类先10款；不等同授权制作完整角色编辑器或运行时衣柜。

用户反馈已证明，分别生成通用人体和衣鞋再缩放配准、旧脸覆盖新身体，以及按颜色连通块提取五官邻近发型的过程不适用。旧方案和失败批次已退役，不能作为当前制作步骤。

- [唯一人体管线](../character-art-pipeline.md)：后续所有人体必须遵循。
- [当前母版及认可参考](../../../art/design/character-bodies/README.md)：区分当前选中母版、旧A/B和家庭体型参考。
- [Astra复盘结论](NPC-rework-astra-review.md)：问题原因与方案依据。
- [历史清理记录](../../../art/archive/README.md)：仅恢复用，不计现行验收。

动态人体与衣物组合按统一规范版本2执行：静态接口后先验证单侧四帧运动，再扩四向动作与动态混搭，最后扩体型和运动适配款数。现有静态候选的兼容不自动延伸到运动；设计已更新，动态小样与正式角色接入尚未实施。
