## 接口

- 共享合同C/E为v3默认数据和合法商品集合；SAVE_VERSION=3。
- 容器新增restore_slots(slots: Array) -> bool：先验证全部格子，再深拷贝替换，成功通知一次；非法输入不改变原槽。新增remove_item(id: String, amount: int) -> bool：足量时按槽索引升序扣完再通知一次，不足不动。不允许生产代码直接写_slots。
- PlayerState.migrate_data(value)必须支持1、2、3并返回最新合法副本；valid_data接受支持版本但不修改输入。restore统一先migrate_data再应用。旧规则提取为独立legacy校验，不能用宽松v3规则校验旧档。
- state_schema.default_life不得共享嵌套引用；两个新游戏互不影响。
- 为新商品扩充item_catalog，所有图标必须有有效icon_key；暂无美术的物品在既有图标渲染处使用明确中文缩写占位（生种/番种/生菜/番茄），不得随机映射成蛤蜊。占位仅为开发表现，P05/P06原生验收确认可辨。

最小测试写法（在SceneTree.run中，S为当前PlayerState脚本）：

```gdscript
var s = S.new()
s.bag.add("lettuce_seed", 2)
var raw: Dictionary = s.to_data(Vector2(330, 250))
check("v3_valid", S.valid_data(raw))
var t = S.new()
check("roundtrip", t.restore(raw) and t.bag.count_item("lettuce_seed") == 2)
var before: Dictionary = t.to_data(Vector2(330, 250))
raw.life.wallet = -1
check("reject_atomic", not t.restore(raw) and t.to_data(Vector2(330, 250)) == before)
```
