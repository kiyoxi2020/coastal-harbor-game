# P03：持久化事务与有限买卖

前置P02；仅建立服务、trade规则与测试商户，不开放地图交易按钮。

## 文件与接口

新增scripts/simulation/action_service.gd、life_rules.gd、tests/test_life_transactions.gd；修改scripts/harbor.gd增加perform_action并装配服务。容器方法复用P02。服务/规则返回遵循共享合同B/D。

trade args严格为{direction:"buy"或"sell", account_id:"market", item_id:String, amount:int}。unit_price由合同E配置读取，禁止相信UI传价。buy从市场slots扣种子、玩家bag加种子、wallet扣款、市场cash加款；sell反向转移原料/作物，市场扣cash、玩家加wallet、对应buy_quota扣数量。数量必须1..99且整值；不自动截断成交量。玩家箱子不参与交易。

预检顺序：request→action/args字段→主体/商品/方向许可→数量→来源库存→对方容量→买方资金→收购额度；同一输入须得到稳定错误码。收购限额耗尽但商户现金充足，仍quota_exceeded。市场没钱不能无限收货。

所有new玩法即时成功事件使用：{event_id:"a:<request_id>:<index>", day_id:int, kind:String, source:String, target:String, items:Dictionary, cash:int, reason:String}。cash为非负转移金额；source/target表达方向；外部补给单独kind=external_restock且cash=0。每个事件只表示一次转移；不能将收入和付款写成两笔金额再相加。

## 验收：测试夹具与精确期望

每例重建默认state，位置[330,250]。request_id从1开始，除注明不复用状态。

| ID | 操作 | 期望 |
|---|---|---|
| buy_two | 买lettuce_seed×2 | 玩家100→90、种子2，市场1000→1010、库存20→18，seq1 |
| sell_clam | 夹具玩家clam×2，卖2 | 钱包116，市场984、clam2、clam额度10；玩家clam0 |
| no_money | 钱包4买生菜种子1 | insufficient_funds，全快照不变，未写盘 |
| no_stock | 买21颗生菜种子 | insufficient_stock，全快照不变 |
| full_bag | 24格各99海带，买种1 | inventory_full，全快照不变 |
| market_poor | 市场现金7，玩家卖clam1 | insufficient_funds |
| quota | 市场clam额度0，卖clam1 | quota_exceeded |
| duplicate | buy_two成功后对next_state复用相同id1与args | duplicate=true，假Save调用仍1次，种子仍2 |
| id_collision | 已成功id1，再id1买番茄种子 | stale_request，全快照不变 |
| skipped_id | 初始用id2 | invalid_request |
| save_failure | 假Save拒绝买2 | save_failed，原wallet100/种子0/seq0；同id1重试可成功 |
| bad_amount | 0、-1、0.5、100 | invalid_amount，不扣库存 |

跨快照对账：buy_two前后玩家+市场现金总和1100不变，种子总量20不变。对sell亦同。每个失败都比较整个to_data，不只数钱。

可直接采用的关键断言（Service通过构造器注入假Save）：

```gdscript
var result: Dictionary = service.execute(s, Vector2(330,250), "trade", {
    "direction":"buy", "account_id":"market", "item_id":"lettuce_seed", "amount":2
}, 1)
check("buy", result.ok and result.next_state.life.wallet == 90)
check("original_untouched", s.life.wallet == 100 and s.bag.count_item("lettuce_seed") == 0)
```
