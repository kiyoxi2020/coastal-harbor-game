正式改图使用GPT内置imagegen；保留[初稿提示词](prompt.txt)、[四向编辑提示词](atlas-edit-prompt.txt)、[眼睑单独修订提示词](eyelid-only-prompt.txt)及对应生成原图。首张单人稿改变几何而否决；四向稿补上眉毛但未明显缩短眼睑，随后根据原图实际钩线位置与用户红箭头仅修尾端。最终只从eyelid-only-edit.png提取指定区域。源图和构造/遮罩/纹理哈希见manifest.json，原生证据独立绑定到本版。
