# 完整键盘导航（2026-10-20）

## 行为

- WASD与方向键等价，E确认，B/Tab/Esc返回。
- 背包格内按6列移动；顶部向上到筛选，再上到菜单标签。左右选择个人/设置等标签，E打开。
- 筛选行最右侧向右进入右侧操作，保留选中物品；操作区上下在移动/丢弃/整理间移动，左右可到拆分。也可从格子边缘进入邻近控件。
- 筛选选择首个匹配物品，方向键跳过禁用控件；待移动/拆分时光标只预览目标，E才提交，不能越出格子误操作。
- 设置左右/WASD横向调整聚焦音量滑块，上下离开滑块选择其他控件。
- 买卖页初始聚焦当前商品，左右选择，向上到买/卖标签，向下到数量加减；横向到确认按钮，E买/卖。空白格、隐藏/禁用控件不进入导航。
- 交易提交期间不重置焦点；结束后恢复原按钮，只有按钮确实不可用才回到当前商品。名字输入仍正常打字，模态导航不越到背后页面。

## 文件

scripts/ui/keyboard_navigation.gd按当前页面/模态中的可见可用控件计算邻近焦点；journal.gd处理网格、区域、滑块与WASD映射；trade_page.gd提交后恢复焦点。场景和局部主题使用已有轻量焦点角标，保持GPT贴图背景/按钮。
