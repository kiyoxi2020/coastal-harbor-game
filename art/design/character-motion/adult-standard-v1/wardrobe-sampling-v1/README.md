# 衣物组合抽样试玩

按用户要求，每类动作抽取一组完整动作，不遍历全部衣物、方向和动作组合。本轮是同版型的衣物设计适配；不据此宣称其他剪裁、体型或完整衣柜兼容。

双击[启动试玩](launch-game-trial.command)，在画面中上部偏右“衣物组合抽样”标题下选择五个样例；左侧可暂停、逐帧。所选样例的动作和朝向固定，避免混入未采样组合。世界角色停步、工具结束时使用同配方站姿，不读写玩家存档。

| 样例 | 衣物组合 | 世界操作 |
|---|---|---|
| 西向走路 | 海军条纹衫＋深蓝牛仔裤＋原棕鞋 | A／← |
| 东向跑步 | 砖红毛衣＋原长裤＋棕色搭扣鞋 | D／→，自动跑步 |
| 西向锄地 | 海军条纹衫＋原长裤、棕鞋 | G |
| 南向浇水 | 原蓝长袖＋深蓝牛仔裤＋棕色搭扣鞋 | F |
| 北向收获 | 原蓝长袖＋深蓝牛仔裤＋原棕鞋 | H |

每组保留完整GPT源、提示词、失败稿、逐姿态部件归属、衣物覆盖与前后层序；实际按独立槽位制作再烘焙到已有角色播放时间轴。身体、脸手和工具取同一姿态的已认可母版，禁止跨姿态贴脸或局部缩放挪衣。walk/run的1024源按整帧固定密度2→1投影，原始源保留；农事保留原源密度2与登记根点。
