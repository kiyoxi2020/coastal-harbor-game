# 四向步行接触基线（2026-10-25）

用户已认可当前四向画面、两套上衣和速度，绑定见../../visual-acceptance.json。本次新增原生移动384个样本，覆盖四方向的左右支撑脚；没有更改纹理、角色位移、衣鞋锚点或速度。

## 测量结果与含义

同一支撑姿态内，脚点减去固定地面参考点后，最大观测跨度四方向均约21.6渲染像素。完整80ms源帧对应的理论位移为72×4×0.080＝23.04渲染像素；75%速度同时放慢移动与动画，单帧总位移不变。观测只覆盖帧内部分时段，故21.6是采样下界。原生对照板保留原裁切像素，镜头平移通过同一地面参考点抵消。

**这不是规范验收失败。** 规范第7节的≤1像素是“支撑脚轨迹及工具握点相对批准姿态的最终屏幕误差”，不能擅自改成每帧期间相对地面零位移。result.json中的passed=false仅表示额外的1像素锁脚诊断未通过，不是撤销用户认可，也不表示新回归。批准的连续目标轨迹尚未登记，因此规范轨迹误差保留未测，不能宣称全关节/接触合同已冻结。

脚点坐标来自已有近似人工观察。同一姿态内做差可抵消固定锚点偏差，但不能用这一方法验证帧间脚点位置、绝对落地精度、隐藏关节或工具握点。A/B共享身体、裤鞋；本次采样A，B没有单独重新采样。
