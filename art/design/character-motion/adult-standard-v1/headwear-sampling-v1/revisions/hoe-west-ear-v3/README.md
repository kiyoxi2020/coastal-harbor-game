# 西锄第三帧：耳后发片修复 v3

## 问题范围与原因

本次耳后露肤是**头发＋帽子特有的问题**。同一姿态的只加头发状态在反馈记录的六个位置均由真实发像素覆盖；发帽状态此前在这些位置直接露出原头皮。两种状态使用不同发片，问题来自 GPT 帽下发的耳后内轮廓开口，非运行时额外位移。原完整短发在帽体上方仍有少量不兼容像素，不能整张复用。

## 修复

保留帽下前发，仅按明确姿态接口选取同姿态原 GPT 完整短发的后发视图，二值选择原 RGBA 与自然 alpha，不补色、不缩放、不挪动、不擦身体。选择轮廓、两份来源 SHA 和各自 ownership 分别保存在 `sample-build/ear-repair/manifest.json`。帽子、原身体和完整 hair-only 状态保留；其余19个显示状态和全部时序逐 SHA/数值保持。新增后发没有引入帽檐上方穿出帽体的像素，列轮廓仅用作诊断，未用于删发。

`build_repair.py` 从冻结 v2 检查全部输入后生成独立候选，拒绝覆盖现有交付；`check_repair.py` 先对旧资源产生 `baseline-failure.json`，再对新资源产生 `asset-checks.json`。软 alpha 发片叠在原身体上按标准 alpha 合成验证，不把原 hair-only 烘焙结果的 alpha 误当合成后值。
