# v5 东向 run 四帧：帽下压发可见视图

本目录仅从现有 GPT `under-hat-hair-sources/source-v1.png` 提取栗色帽下发，不再生图，不修改原身体、正式帽、原完整发、catalog 或 Godot。实际执行模型为 `gpt-6.1-sol`，职责为独立提取及来源/离线合成检查；集成与原生验证由主代理执行。

## 来源、归属与视图边界

完整 1254×1254 原图到 1024×1024 的 nearest 归一关系已逐字节验证；2×2、每格512×512、row-major 对应 `run_east_0..3`。每格原 RGBA 放入512×768全帧左上，下面256行透明。源图是不透明穿戴画面，alpha255没有被用作“这是头发”的证据。

正式提取仅读取各姿态冻结的 `source-contours.json` 逐行像素范围。初始颜色/连通域只是经逐姿态头部几何限制的定位辅助；本次已同时目视完整源、分离 plate、原身体加正式帽合成的2倍头部图，审查刘海、前侧垂发、耳周、后脑和后颈。眉部、眼部、耳皮肤及耳黑弧、脸外竖线、衣服与背景均不作为头发所有者。前额右侧的生成脸黑线尾端也不随发提取。正式重建脚本不重新运行颜色分类；初始草拟程序保留为 `draft_source_ownership.py`，其重跑仅输出 `draft-regeneration/`，不覆盖冻结轮廓。

这里是**仅戴这顶帽时使用的可见刘海/鬓发/后发/后颈组合视图**。帽冠遮住而没有画出的完整裸头发不在此源中，不声称存在。`hair` 单独状态继续引用原完整源及原注册部件；每帧审计记录原完整源、注册发及 hair-only 烘焙图SHA，未覆盖它们。没有按 max-y 削发，没有补画、改色、缩放或以截平后脑修穿模。

## 验证与交付条件

四帧各12项来源/归属/登记/合成检查通过：完整归一及格子来源正确；所选RGBA与实际源一致；未选plate为透明零；冻结轮廓精确重建；零登记只烘焙一次；源及登记所有权一致；具体眉/眼/耳/脸/衣/背景反例排除；原身体SHA匹配正式帽输入；近远合成顺序精确；全部发帽支持区外原RGBA差异0（包括透明RGB）；原hair-only烘焙SHA不变。运行 `python3 validate_and_manifest.py` 可复核，逐帧 `audit.json` 和 manifest 绑定实际文件SHA。

四帧的明暗背景全身图与头部2倍分层图已目视，没有观察到头发穿出帽冠/帽带，也没有机械横切后发。原图1254方、归一图1024方、注册输出512×768均保留；按现有 display_scale 0.2371134，整帧显示约121.4×182.1屏幕像素。资源没有再次预缩。
