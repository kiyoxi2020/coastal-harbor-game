# 游戏港口场景步行体验

2026-10-24，按用户“速度有点快，放入游戏体验”的要求增加独立开发入口。直接复用游戏港口地形、碰撞、深度排序和4倍镜头，读取现有GPT小样的8张烘焙图。没有存档服务，不读写玩家档；正式游戏入口及角色仍保持原状。

## 启动与操作

- 双击本目录`launch-game-trial.command`；或在Godot编辑器打开`godot2d/dev/character_walk_trial.tscn`后按F6运行当前场景。
- **A / ←**：向西步行，松开保留当前姿态；目前没有新的idle或其他朝向。
- **R / 回起点按钮**：明确回到起点；到边界后可重复体验。
- **1 / 2 或短袖/长袖按钮**：切换衣物，保持同一动作相位。
- **滑条 / − / +**：速度50%–100%，默认75%。**Esc / 退出体验**关闭窗口。

默认从72降为54世界单位/秒；每帧80ms改为约106.7ms。50%对应36单位/秒、160ms/帧；100%恢复原始小样速度。动作时钟按实际西向位移推进，碰撞恢复的反向微移不计为走路。换衣/调速不重置相位。

窗口使用游戏原生2560×1440渲染、默认1280×720窗口；源图512×768完整读取。统一世界缩放138/582/4，与游戏镜头配合后可见人物约138–140渲染像素高，默认半尺寸窗口约69–70显示像素。使用nearest，无单独衣鞋变形。窗口拉大可按实际游戏显示体验。

## 验证

- 21项隔离检查通过：来源加载与篡改拒绝、默认降速/时间比例、换衣同相位、实际移动/停止、真实边界、碰撞恢复、显式回位及正式入口保持。
- 18项Apple M4原生检查通过：真实键鼠、滑条/按钮、54单位速度、实际位移时钟、五张原生截图、界面范围和人物尺度。
- 已目视短袖/长袖在港口道路中的原生截图。来源、场景脚本哈希和检查记录位于[evidence/game-trial-2026-10-24](evidence/game-trial-2026-10-24/metadata.json)。这次验证不是完整生产遮挡/门/农事流程或跨平台验收。

仅西向动作体验，未镜像伪造其他朝向，也未把新版walk与旧版其他动作混用。旧小样80ms原生证据不被覆盖；本次速度是独立体验参数。用户外观/速度认可仍待反馈，未代表阶段3通过或全套人物迁移。未提交、推送或导出。
