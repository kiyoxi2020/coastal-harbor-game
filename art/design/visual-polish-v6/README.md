# 背包导航与场景精度修订（2026-10-20）

## 根因与修复

1. 背包方向键只触发Godot默认焦点导航，selected_index未变化。journal现拦截非模态背包方向键，同步6×4格位置与焦点；边界不换行、不越界，筛选禁用格跳过。按住方向键的echo允许重复移动。移动/拆分待操作时只预览，E才调用select_slot，避免光标一移动就改库存。数量模态框不截获。
2. 海产旧代码图只有约12×10有效像素，UI多倍放大而作物是详细贴图。内置GPT制作三种海产，规范化为64×64透明图；forage_pickup.gd仍为场景与UI共享入口，现在绘制同一贴图，世界占位12×11和采集规则不变。UI独立显示scale5.25，使海产与作物可见大小接近。
3. 原花丛128×112图含细密草垫，0.125缩放后世界16×14，底色和地面不一致。GPT重制不带地面/草垫的稀疏花与草束，nearest处理为16×14，场景scale1、offset(0,-7)，原位置/世界占位不变；岩石、土壤、作物和碰撞不改。

## 素材

atlas-original.png为内置GPT原图（4×2：蛤蜊/海螺/海带/草束，白花/黄花/粉花/边缘花）；build_assets.py只裁透明边界并nearest规范化，不重新绘制。metadata.json记录源区域、实际裁边、输出大小、世界尺寸和脚点。运行图assets/visual-polish-v6，旧素材保留。

GPT未严格对齐两行，海带越过图集等分行线；切图按实际上下两排间隙分区（上排0..0.58H，下排0.62H..H），避免把上排残片带入花丛裁边。花/草源图无铺地，透明空隙已做资源检查和实际渲染核对。
