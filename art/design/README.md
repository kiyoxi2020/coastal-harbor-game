# 美术目录索引

生产加载的资源位于`godot2d/assets/`，本目录保存原图、提示词、制作元数据和评审证据。目录存在不代表已接入游戏或获得认可。

| 入口 | 当前用途与状态 |
|---|---|
| [player-unified-v4](player-unified-v4/README.md) | 当前正式主角与动作来源；新版全面验收前保留运行依赖 |
| [P11-restaurant](P11-restaurant/README.md) | 已接入餐馆的GPT来源及原生证据 |
| [人物资源库](../characters/README.md) | 现行母版、动作、衣裤鞋发帽、源与评审统一入口；旧character-*制作目录由Git379a9bc恢复 |
| [npc-modular-v2](npc-modular-v2/README.md) | 旧外观/年龄比例历史参考；不是第二套现行人体管线 |
| [archive](../archive/README.md) | 历史失败稿本地恢复包与可追溯清单，不作为现行制作依据 |

唯一人物制作规范为[人体管线](../../docs/design/character-art-pipeline.md)。后续只维护一个现行人体体系；历史源图作为参考保留，待新体系完成动作覆盖与验收后再统一移除旧生产依赖。其余玩法美术按各自目录README管理，人物资料已按引用核验迁往art/characters，玩法美术和在用player-unified-v4不受此次目录整理影响。
