# 返乡青年 · Blender 人物与动作 v1

2026-10-09。仅完成 Blender 阶段；Unity 工程、原占位人物和原场景未修改。模型、绑定、姿态和图片均由实际 Blender 文件生成，不是概念图。

## 打开与播放

使用 Blender 5.2.1 打开 `returnee.blend`。文件不依赖外部贴图，人物与摄影棚分别在 `Returnee`、`Studio` 集合。

1. 选中 `Returnee_Rig`。默认载入 Idle，时间轴 1–60，按空格播放。
2. 将一个编辑器切换到 Dope Sheet → Action Editor，通过 Action 选择框切换 `Walk` 或 `Run`。
3. 将场景播放结束帧改为下表的“播放范围”。额外的闭合末帧用于核对首尾，循环播放时不重复它。
4. Pose Mode 中可选骨骼编辑；骨骼名称按身体部位与 `.L` / `.R` 标记。原地循环，不含前进位移。

| 动作 | 播放范围 | 闭合末帧 | 帧率 | 内容 |
| --- | --- | --- | --- | --- |
| Idle | 1–60 | 61 | 30 fps | 轻微呼吸与放松站立 |
| Walk | 1–32 | 33 | 30 fps | 交替迈步、摆臂、重心升降 |
| Run | 1–24 | 25 | 30 fps | 更快的步频、抬脚和曲肘摆臂 |

骨骼关键帧已烘焙，可编辑，但当前没有单独的动画师 IK 控制器。腿部求解器在生成阶段使用，文件内不是实时足底 IK 系统。

## 外观与结构

- 清新动画化返乡青年：珊瑚外套、青绿长裤、黄色短靴，完善五官、短发、翻领、拉链、口袋、袖口、鞋底。
- 当前待机高度约 1.692 m，约 4.68 头身（头高不含头发）。
- 22 根骨骼，78 个角色网格对象。基础网格 28,196 个三角面，含细分等修改器的当前求值结果 56,916 个三角面。
- 768 个基础顶点使用混合权重，实际每顶点最多 2 根骨骼影响，权重归一。面部、头发、鞋等刚性部件单骨影响属于有意设计。
- 手部为带拇指的简化并指造型，不含独立手指骨骼和面部表情绑定。

## 验证结果

`validation.json` 来自重新打开保存文件后的检查，当前通过：骨骼存在与层级、网格绑定引用、顶点权重、待机膝部姿态、三组 Action、左右臂腿反相摆动、首尾矩阵闭合、所有帧足底高度、变形顶点有限性。

三动作首尾骨骼矩阵误差为 0；足底接触高度误差约 0.000001 m，无本轮检测到的落脚悬浮或脚底穿地。抬脚离地峰值约：Walk 0.102 m，Run 0.207 m。浮点数极小误差不表示物理仿真精度。

画面复核修正了领口与内搭相交、发束／嘴部离开表面、初始鞋底偏高、待机过度屈膝，以及臂腿摆动相位。预览视频用于审阅剩余的风格与节奏问题；自动检查不等于完整穿插检测或用户审美验收。

## 下一阶段之前

先验收外观、头身比例和动作节奏，再接入 Unity。尚未完成统一 UV、贴图烘焙、材质／网格合批、LOD、FBX／Humanoid 导入、坡地脚部适配或引擎行走验证。当前网格为可编辑审阅版，不应直接当作发布级游戏角色。

Walk 的初始步幅匹配速度约 0.80 m/s，Run 约 2.01 m/s。它们与现有 Unity 控制器速度不一致；后续必须共同校准动画播放速度和实际移动速度，不能直接挂接后便认定不会滑步。

## 重建

上一级的 `build_character.py` 负责造型和绑定，调用 `animate_character.py` 生成三组动作。`validate_character.py` 重开文件验证；`preview_character.py` 提供 `hero`、`views`、`poses`、`animation`、`rig` 五种预览模式。

重建会覆盖本版本 `.blend`，手工编辑后请先另存新版本。原占位人物仍在项目原来的 Blender 场景中。
