## 完整源、halo和隐藏区

原shirt图的胸腹布料连续，未目视发现永久手掌形洞。前景手掌下的完整源仍保留；不能把诊断图中的可见空白裁入正式通用torso源。

两张shirt源都有蓝黑低alpha外圈光晕。原shirt归一后的alpha>0 bbox=[103,342,469,537]，alpha≥128为[105,357,407,536]；原始源的详细阈值统计见JSON。光晕只能由人工确认的真实布料边界source ownership排除，不能把alpha阈值独自当正式mask。源最大alpha=254，原B资源也为254；不能因没有255就误判整图不透明度错误。

**完整B torso隐藏支撑仍缺139个alpha≥128源点，bbox及逐点见JSON。** 原两袖完整支撑无缺点。这139点位于当前真实torso occlusion隐藏的侧边，当前可见30655点不受影响；因此可推进这个固定pose的有限表面适配，但不能宣称完整B层逐点还原、任意遮挡关系或后续混搭均可用。需要露出这些侧边时必须补相应完整源表面，不能复制旧蓝衫或程序补色。

## 正式准入所需mask与层序

- source ownership：人工确认各源真实布料/深色轮廓，排除skin/光晕，保留原RGBA软边；原源与领口源分别绑定，完整torso和袖源不得永久挖手洞。
- target coverage：沿原B同版型的具体torso/左右臂表面及原hide_mask含义登记；这里的高置信可见支撑不能代替完整目标覆盖合同。
- 近手遮挡：维持原六层顺序 `body_head_neck_lower → shirt_torso → body_arm_left → B_arm_left_sleeve → body_arm_right → B_arm_right_sleeve`，所有offset为0；原脸手/裤鞋像素保留，不把新整衣层置于全部手掌之前。

本轮只测源、登记诊断polygon及证据，未生成正式衣层/人物合成或改仓库。可以继续正式来源准入和统一合同验证；当前已知可见材料不再需要因领口缺图继续生图。有限隐藏侧边和原生/软边验收边界必须随适配保留。
